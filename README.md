# OneDollarIOS

Pirate-group one-dollar auction iOS wrapper, plus related 寶輝科技 web tools.

- iOS App Store WebView: `OneDollarIOS/`
- Codemagic workflow: `codemagic.yaml`
- 寶輝現有後台電子發票（PHP，對 `F:\Web\baohui-staging`）: [`web/baohui-staging/`](web/baohui-staging/README.md)
- 實驗用 Node 後台（不是線上那套）: [`web/baohui-admin/`](web/baohui-admin/README.md)
